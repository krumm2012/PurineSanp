# PurineSnap 嘌呤智探: 微信小程序端 + 管理后台一体化系统

> 专为关注日常健康防范与低嘌呤均衡饮食人群打造的智能拍照测嘌呤与健康分析系统。系统采用 **微信小程序真实视口与交互规范（移动端小程序）** + **简易运营管理后台（Web Admin Console）** 双端架构，提供高保真小程序体验、AI 多模态菜品成分拆解、权威生化数据库（PubChem/黄嘌呤代谢链）、三色红绿灯安全预警、个性化补水建议与后台食物库/数据监测管理。

---

> 1. **微信小程序原生视觉与交互（Mini Program Client）**：

> 2. **简易管理后台（Admin Console）**：
>    - 支持从顶部或管理快捷入口一键切换至“简易管理后台”，包含：

> 3. **微信小程序代码结构与部署说明**：
>    - 提供小程序端核心 API 对接接口与数据结构定义，便于导出或对接微信开发者工具。

## 1. Overview & Core Concept

- **What It Does**:
  - **小程序端（用户主视角）**：
    - **拍照识菜与智能拆解**：调用摄像头拍照或从相册上传餐食图片，AI 瞬间拆解菜品原料、预估克数与嘌呤总量；
    - **分量滑动微调**：在微信风格半屏抽屉中，直接拖动滑块增减克数或替换食材，核对无误后一键存入微信饮食档案；
    - **三色安全红绿灯**：超低嘌呤（$<50\text{mg}/100\text{g}$ 绿色安全）、中嘌呤（$50\sim 150\text{mg}/100\text{g}$ 黄色适量）、高嘌呤（$>150\text{mg}/100\text{g}$ 红色预警）；
    - **个性化补水与排酸建议**：依据摄入嘌呤动态计算当日排泄需水量，生成分时饮水打卡与碱化尿液食谱搭配建议；
    - **生命科学 PubChem 图谱**：实时展示腺嘌呤、鸟嘌呤、次黄嘌呤、黄嘌呤与尿酸的生化分子结构（PubChem 官方 CID 与 2D 拓扑图）及黄嘌呤氧化酶（XOD）代谢通路。
  - **管理后台（运营/管理视角）**：
    - **数据概览**：总打卡人次、平均摄入嘌呤量、超标告警占比分布；
    - **食物库管理 (CMS)**：随时扩充地方菜系与包装零食嘌呤数据库；
    - **健康规则与系统配置**：灵活调整不同健康模式（防范期/控制期/运动期）的预警阈值。

- **Target Audience / Persona**:
  - 关注体检尿酸、希望在手机微信中随时拍照测嘌呤的大众用户；
  - 负责机构或家庭饮食管理的管理员/营养师。

## 2. User Experience & Visual Design

### Double-View Experience (双视角架构)
1. **微信小程序端视图 (WeChat Mini Program View)**:
   - **顶栏规范**：微信标准标题居中，右侧带官方微标胶囊按钮（`···` 更多菜单、`○` 关闭退出）；
   - **主页**：今日嘌呤摄入进度环（当前摄入 / 300mg 上限）、安全状态徽标（绿色安全/黄色注意/红色预警）、早中晚三餐时段卡片；
   - **拍照识图页**：沉浸式取景窗与图片上传，识别后弹出标准半屏 PageContainer 抽屉，支持食材克数滑块微调与餐别切换；
   - **科学与补水页**：水分代谢水杯打卡器、按时补水提醒、PubChem 分子生化视窗；
   - **食物库页**：微信 SearchBar 实时检索，肉/海鲜/豆/蔬/饮品分类标签切换；
   - **底部 TabBar**：微信风格 4 标签栏（打卡、测嘌呤、补水/生化、食物库），平滑切换。
2. **简易管理后台视图 (Admin Console View)**:
   - 响应式左侧侧边栏导航 + 顶部操作条（支持一键切回“小程序预览”）；
   - 模块 1：**饮食监测流水**（表格展示用户提交记录、菜品拆解明细、红绿灯状态、超标告警）；
   - 模块 2：**食物嘌呤 CMS 库**（支持新增食材、修改嘌呤数值、重设红绿灯等级、批量重置）；
   - 模块 3：**系统参数与 AI 配置**（Gemini 3.8 Flash 提示词、健康阈值 300mg / 150mg 切换、导出小程序配置）。

### Visual Identity & Theme
- **小程序端**：遵循微信 WeUI 3.0 与苹果 iOS Human Interface Guidelines，背景 `#EDEDED` / 纯白卡片 `#FFFFFF`，微信经典质感绿 `#07C160` 与科学深蓝 `#0284C7` 融合。
- **后台端**：极简清爽的 SaaS 仪表盘风格（`#F8FAFC` 与 `#FFFFFF`，单像素边框 `border-slate-200`，Tabular Numerals 字体）。

## 3. Key Product Decisions & Trade-Offs

- **Decision 1: 小程序体验呈现模式（双端一体化无缝切换）**
  - *Chosen Approach*: 默认呈现精美的高保真微信小程序界面（居中 iPhone 视口，配有微信经典顶栏胶囊与底部 TabBar），右上角提供全屏模式与“切换至管理后台”快捷入口。
  - *Why*: 既能在 AI Studio Web 环境下 100% 还原微信小程序的原生单手触控操作习惯，又满足了用户对“简易管理后台”的运营管控诉求。

- **Decision 2: 菜品多模态识别与双重校准**
  - *Chosen Approach*: 采用 `gemini-3.8-flash` 多模态视觉 API 拆解照片中每一种食材成分及克重，并与本地权威食品嘌呤数据库（mg/100g）自动关联核验，红绿灯判定客观严谨。
  - *Why*: 既能从一盘复杂的复合菜肴（如红烧牛肉豆腐煲）中剥离各食材，又能确保单项嘌呤数据符合国家食品科学标准。

- **Decision 3: 数据同步与后台 CRUD**
  - *Chosen Approach*: 统一由前端状态引擎结合 LocalStorage 实现小程序端饮食记录与后台管理数据库的实时双向联动。在后台新增或修改食物嘌呤值后，小程序端实时更新。

### Key Data Entities
- `MealRecord`: `id`, `timestamp`, `mealType`, `dishName`, `photoUrl`, `ingredients: [{ name, weightGrams, purinePer100g, totalPurineMg, category }]`, `totalPurineMg`, `trafficStatus`, `aiNotes`
- `FoodDatabaseItem`: `id`, `name`, `category`, `purinePer100g`, `trafficLevel: 'green' | 'yellow' | 'red'`, `servingUnit`, `pubchemCid?: number`, `notes: string`
- `AdminSystemConfig`: `dailyPurineLimitMg: number`, `waterPerPurineMg: number`, `aiModel: string`

### Implementation Steps
1. **Server (`server.ts`)**: 搭建 Express 服务，集成 `@google/genai` 提供 `/api/analyze-meal` 菜品多模态智能拆解。
2. **核心数据与生化知识库 (`src/data/*`)**: 权威食物嘌呤库（120+种食材）与 PubChem 5大核心化合物代谢通路（腺嘌呤、鸟嘌呤、次黄嘌呤、黄嘌呤、尿酸）。
3. **微信小程序端组件 (`src/components/miniprogram/*`)**:
   - `MiniProgramContainer`: 模拟微信视口、状态栏、胶囊按钮、沉浸模式切换；
   - `HomeTab`: 进度环、三色预警、三餐记录流；
   - `CameraAnalyzeModal`: 拍照/传图、骨架识别动效、食材滑动微调抽屉；
   - `ScienceHydrationTab`: 补水打卡、尿酸排泄动力学、PubChem 2D 结构图谱；
   - `FoodWikiTab`: 微信风格搜索与分类；
   - `MiniTabBar`: 底部原生感 4 项导航。
4. **管理后台组件 (`src/components/admin/*`)**:
   - `AdminDashboard`: 饮食流水与超标监测表格、统计图表；
   - `FoodDatabaseCMS`: 食物库增删改查、嘌呤参数校准；
   - `SystemSettings`: 每日阈值设定、提示词微调、小程序配置导出。
5. **编译与类型验证**: 运行 `compile_applet` 确保零错误。
